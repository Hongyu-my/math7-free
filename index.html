第1章 有理数

知识框架：正数负数 → 有理数分类 → 数轴 → 相反数／绝对值 → 有理数大小比较

① 负数一出场，数系变立体。有理数 = 整数 + 分数。0 既不是正数也不是负数，是正数负数的分界。

② 数轴三要素：原点、正方向、单位长度。数轴上右边的数总比左边大。

③ 绝对值 = 到原点距离，永远非负。正数本身是它，负数是相反数，0 还是 0

④ 相反数：只有符号不同的两个数，0 的相反数是 0。

典例1：a=−3，b=5，比较 a、b、|a−b| 的大小。

解：a−b=−8，|a−b|=8。−3 < 5 < 8，即 a < b < |a−b|。答案：a < b < |a−b|

点睛：先算绝对值再比大小；别把 |a−b| 直接当 a−b。

典例2：|x|=3，求 x。

解：到原点距离 3 的点有两个：3 和 −3。答案：x=±3

点睛：绝对值方程常两解，别漏负的。

题型·坑点

题型A 绝对值化简：先判内部符号。坑：不分正负直接去绝对值。

题型B 数轴比大小：右大左小。坑：负数比大小搞反（−5 < −2）。

拓展拔高（补习班专题）
专题1 数轴动点问题
例：数轴上 A 在 −2，B 在 4。点 P 从 A 以 1 单位/秒向右，点 Q 从 B 以 2 单位/秒向左，几秒后相遇？相遇点表示几？
解：设 t 秒，P=−2+t，Q=4−2t。相遇 −2+t=4−2t ⇒ 3t=6 ⇒ t=2，位置=0。答案：2秒后在点 0 相遇。
套路：动点位置 = 起点 ± 速度×时间（右加左减）；相遇令相等，中点用 (左+右)/2。
专题2 绝对值的几何意义（|x−a| 的套路）
例：求 |x−1|+|x−3| 的最小值及 x 范围。
解：|x−1| 是 x 到 1 的距离，|x−3| 是 x 到 3 的距离。当 x 在 1 和 3 之间时，两距离之和恰为 1 到 3 的距离=2，最小。答案：最小值 2，1≤x≤3。
口诀：两点间线段最短，x 落中间取最小。
专题3 新定义运算（考试常客）
例：规定 a⊕b = a²−b，求 (−2)⊕3。
解：代入公式得 (−2)²−3=4−3=1。答案：1。
招：把新符号当成"套公式"，老老实实代入，别自己发明规则。
易错：
  • 认为"带负号的数都是负数"（−(−3)是正数）；
  • 绝对值化简不判内部正负；
  • 负数比大小方向反；
  • |x|=a 漏掉负解 x=−a。
口诀：0非正非负绝对值非负右大左小|x−a|表距离

点"−1 / +1"移动点 A，看 |a| 怎么变。负数也变正距离——距离永远非负。

第2章 有理数的运算

知识框架：加减 → 乘除 → 乘方 → 混合运算 → 近似数／科学记数法

① 加减——符号是命门。同号相加取同号；异号相减大减小，符号跟着大的数跑。

② 乘除：同号得正，异号得负，绝对值相乘除。0 不能做除数。

③ 乘方最容易被括号坑。(−2)²=4，−2²=−4。负号在括号里才参与平方

④ 混合运算顺序：先乘方，再乘除，最后加减；有括号先算括号。

典例：计算 −3² + (−2)³ ÷ (−4) − |−5|。

解：−9 + (−8)÷(−4) − 5 = −9 + 2 − 5 = −12。答案：−12

点睛：−3²=−9 不是 9；先乘方后乘除最后加减。

题型·坑点

题型A 乘方符号：指数奇偶决定。坑：(−2)² 与 −2² 混淆。

题型B 混合运算：严格顺序。坑：运算顺序错、科学记数法格式错（1≤|a|<10）。

拓展拔高（补习班专题）
专题1 乘方的符号规律与"奇负偶正"
例：(−1)ⁿ 当 n 为奇数、偶数时各是多少？
解：底数是 −1，奇次幂=−1，偶次幂=1。答案：奇 −1，偶 1。
延伸：−1 的奇偶次幂是压轴小题常客，记牢"奇负偶正"。
专题2 巧算与规律探究（裂项、凑整）
例：计算 1−2+3−4+…+99−100。
解：两两分组：(1−2)+(3−4)+…+(99−100)= (−1)×50 = −50。答案：−50。
套路：符号交替、项数成对时先分组；裂项形如 1/(n(n+1))=1/n−1/(n+1)。
专题3 程序框图 / 数字规律
例：按"输出 = 输入²−1，再取相反数"的规则，输入 −3 输出多少？
解：(−3)²−1=8，取相反数=−8。答案：−8。
招：框图题一步步代，注意"先算后取反"的顺序。
易错：
  • 认为带负号的乘方都负；(−2)²与−2²混淆；
  • 运算顺序错：先算加减后乘方；
  • 0 做除数；
  • 科学记数法 a 不在 1~10 之间。
口诀：异号相减大减小带大号同号得正异号得负负号进括号才平方先乘方再乘除后加减

🎬 动图演示：乘方，负号在不在括号里差很多

点"换底数"看 (−a)² 和 −a² 的区别：只差一个负号，结果天差地别。

第3章 实数

知识框架：平方根 → 算术平方根 → 立方根 → 无理数／实数 → 实数的运算

① 平方根 vs 算术平方根。正数 a 的平方根有两个 ±√a；算术平方根只取正的 √a。0 的平方根是 0。

② 立方根：³√a 只有一个，负数的立方根是负数。³√(−8)=−2。

③ 无理数：无限不循环小数（π、√2 等非完全平方的根）。实数 = 有理数 + 无理数。

④ 重要区别：√a² = |a|；而 (√a)² = a（要求 a≥0）。

典例1：求 16 的平方根和算术平方根。

解：平方根 ±4，算术平方根 4。答案：±4；4

点睛：问"平方根"要写两个，"算术平方根"只写一个。

典例2：√25 的值？³√(−27) 的值？

解：√25=5；³√(−27)=−3。答案：5；−3

点睛：√25 不是 ±5，算术平方根只取正。

题型·坑点

题型A 开方：分清平方根/算术平方根。坑：√16 写成 ±4。

题型B √a² 化简：= |a|。坑：直接写成 a（忽略 a 负）。

拓展拔高（补习班专题）
专题1 根号估算与"整数部分+小数部分"
例：√10 在哪两个相邻整数间？若 √10 = a+b，a 为整数部分、b 为小数部分，求 a、b。
解：9<10<16 ⇒ 3<√10<4，故整数部分 a=3，小数部分 b=√10−3。答案：a=3，b=√10−3。
套路：找平方夹逼；小数部分=原数−整数部分（必为正）。
专题2 √a²=|a| 与 (√a)² 的辨析
例：当 x<0 时，化简 √(x²)。
解：√(x²)=|x|，因 x<0，=|x|=−x。答案：−x。
提醒：结果要带正确符号，−x 此时是正数。
专题3 实数运算中的化简
例：计算 |√3−2| + (√3−1)。
解：√3≈1.732<2，故 |√3−2|=2−√3。原式=2−√3+√3−1=1。答案：1。
易错：
  • √a 默认指算术平方根，写成 ±√a；
  • √a² 直接等于 a（应 |a|）；
  • 误以为带根号的都是无理数（√4=2 是有理数）；
  • 立方根符号搞错。
口诀：平方根两算术平方根一√a²=|a|立方根符号随原数根号估算用夹逼

第4章 代数式

知识框架：用字母表示数 → 列代数式 → 代数式的值 → 整式（单项式／多项式）→ 合并同类项 → 去括号 → 整式加减

① 代数式 = 数和字母用运算符号连起来。单独一个数或字母也是代数式，不写"="和">"。

② 单项式看两个"数"。系数=数字因数（含π）；次数=字母指数和。多项式次数看最高次项。

③ 合并同类项——只有 twins 才合。同类才合并，系数加减字母指数留

④ 去括号，符号看"门脸"。前是"+"不变，前是"−"全变号，且前系数要乘进每项。

典例1：化简 3x − 2(x − 4y) + 5y。

解：−2 乘进：−2x+8y。得 3x−2x+8y+5y = x+13y。答案：x+13y

点睛：−2×(−4y) 算成 −8y（应为 +8y）是典型错。

典例2：a=−2，b=3，求 2a²b − 3ab + a²b。

解：合并=3a²b−3ab。代入：3×4×3 − 3×(−2)×3 = 36+18 = 54。答案：54

点睛：代入负数加括号；(−2)²=4。

题型·坑点

题型A 化简求值：先合并再代入。坑：系数含π当字母；常数项也是同类项。

题型B 去括号：乘进每项、负号全变。坑：漏乘、漏变号。

拓展拔高（补习班专题）
专题1 整体代入（已知局部求整体）
例：已知 x+y=5，xy=2，求 2x+2y−3xy。
解：2x+2y−3xy = 2(x+y) − 3xy = 2×5 − 3×2 = 10−6 = 4。答案：4。
套路：别傻求和 x、y，把 (x+y)、(xy) 当整体直接代。
专题2 赋值法 / 特殊值判断恒等式
例：判断 "2(a+b)=2a+b" 是否成立。
解：取 a=1,b=1：左=4，右=3，不等 ⇒ 错误。答案：不成立。
招：恒等式证伪只需一个反例；构造题也常用赋特殊值。
专题3 代数式表示规律（找第 n 项）
例：数列 3,5,7,9,… 第 n 项？
解：是首项 3、公差 2 的等差，第 n 项=3+2(n−1)=2n+1。答案：2n+1。
易错：
  • 把π当字母算进次数；
  • 常数项忘记合并；
  • 去括号漏乘、漏变号；
  • "系数1或−1"计算丢项。
口诀：同类项字母指数同系数加减字母留前负去括号全变号整体代入省力气

🎬 动图演示：去括号，符号看"门脸"

门前是"−"全变号，门前是"+"不变。点"去括号"分步看，红=变负，绿=变正。

第5章 一元一次方程

知识框架：方程与等式 → 等式基本性质 → 一元一次方程 → 解法（去分母／去括号／移项／合并／系数化1）→ 实际应用

① 方程思想：把"未知"当"已知"用。设 x，找等量关系列等式再解。这是七年级最重要思维升级。

② 解方程五步法：去分母→去括号→移项→合并→系数化1。移项必变号。

③ 应用题钥匙=等量关系。和差倍分、行程（路=速×时）、工程（量=效×时）、利润（利=售−本）。画线段图、列表。

典例1：解 (x+1)/2 − 1 = (2−x)/3。

解：①×6：3(x+1)−6=2(2−x)；②去括号：3x+3−6=4−2x；③移项：5x=7；④x=7/5。答案：x=7/5

点睛：去分母时 −1 也要×6；移项变号。

典例2：甲乙距240km，甲60、乙40相向而行，几小时相遇？

解：60t+40t=240 ⇒ 100t=240 ⇒ t=2.4。答案：2.4小时

点睛：相向用"加"，追及用"减"。

题型·坑点

题型A 解方程：五步顺序不乱。坑：去分母漏乘无分母项；移项不变号。

题型B 应用：找等量关系。坑："多20"列成"减20"；相向/追及搞反。

拓展拔高（补习班专题）
专题1 含参数方程（解的讨论）
例：关于 x 的方程 2x+a=5 的解是正整数，求 a。
解：x=(5−a)/2 为正整数 ⇒ 5−a 为正偶数 ⇒ 5−a=2、4、… ⇒ a=3、1、…（取合理值）。答案：a=3 或 1（等）。
套路：先用 a 表示解，再按"整数解/正整数解"反推参数范围。
专题2 绝对值方程 |ax+b|=c
例：解 |2x−1|=3。
解：2x−1=3 或 2x−1=−3 ⇒ x=2 或 x=−1。答案：x=2 或 −1。
招：绝对值方程先"去绝对值"化成两个一次方程。
专题3 应用题进阶（分段计费 / 方案选择）
例：打车起步价 10 元(3km内)，超出每 km 2 元。乘车 8km 花多少？
解：10 + 2×(8−3)=10+10=20。答案：20元。
延伸：分段计费先判断落在哪一段；方案选择要列两式比大小。
易错：
  • 去分母漏乘不含分母项；
  • 移项不变号；
  • 去括号负号错；
  • 应用题等量关系错；
  • 绝对值方程漏一解。
口诀：移要变号分母先乘每项应用先找等量关系绝对值方程两分支

第6章 图形的初步认识

知识框架：几何图形 → 线段／射线／直线 → 线段长短比较与和差 → 角（度量／比较／和差）→ 余角和补角

① 线有三兄弟。线段（两端点）、射线（一端点）、直线（无端点）。两点之间线段最短；两点定一直线。

② 中点、角平分线——"一半"关系写准。M是AB中点 ⇒ AM=MB=½AB。

③ 角度是 60 进制！度分秒六十跳，借一当六十

④ 互余互补。和90°互余，180°互补。同角/等角的余角相等、补角相等。

典例1：∠AOB=70°，OC平分，求∠AOC。

解：∠AOC=½∠AOB=35°。答案：35°

点睛：写成2×70°或忘"平分=一半"都错。

典例2：38.5°=?°?′；25°36′=?°。

解：0.5°=30′⇒38°30′；36′=0.6°⇒25.6°。答案：38°30′；25.6°

点睛：按十进制换算（38°50′）是大忌。

题型·坑点

题型A 线段/角计算：用中点、角平分线。坑：2倍与½搞反。

题型B 度分秒换算：60进制。坑：当十进制。

拓展拔高（补习班专题）
专题1 线段计算与分类讨论（动点/不确定位置）
例：AB=10，C在AB上且 AC=3，M、N 分别是 AC、BC 中点，求 MN。
解：MN=½AC+½BC=½(AB)=5（与C位置无关！）。答案：5。
套路：中点连线段=½总长，这类"与动点位置无关"的结论常考。
专题2 角度综合（角平分线+和差+折叠）
例：∠AOB=80°，OC 平分，∠BOD=30°，求 ∠COD。
解：∠AOC=∠COB=40°；若 D 在 OB 外侧，∠COD=∠COB+∠BOD=70°（需看图定内外）。答案：依图 70° 或分类。
提醒：没给图时角的问题常要分类讨论。
专题3 钟面角
例：3点整时针分针夹角？
解：每小时30°，3点=3×30°=90°。答案：90°。
公式：夹角=|30H−5.5M|（H时M分）。
易错：
  • 度分秒按十进制；
  • 中点/角平分线关系写反；

  • 无图题不分类讨论。
口诀：两点之间线段短度分秒六十跳平分就是一半无图题先分类

七下第1章 相交线与平行线

知识框架：两直线相交（对顶角/邻补角）→ 同位角/内错角/同旁内角 → 平行线判定 → 平行线性质 → 平移

① 对顶角相等，邻补角互补。

② 判定与性质，方向相反！判定：由角推平行（角→线）；性质：由平行推角（线→角）。

③ 拐弯模型。平行线间折线，过拐点作平行线，把角"搬"到两侧再相加/相减。

④ 平移：图形整体移动，形状大小不变，对应点连线平行且相等。

典例：AB∥CD，∠B=40°，∠D=30°，求∠BED。

解：过E作EF∥AB，则EF∥CD。∠BEF=∠B=40°，∠DEF=∠D=30°，∠BED=70°。答案：70°

点睛：猪蹄模型两角相加；骨折模型两角相减。

题型·坑点

题型 证明平行/求角：先判定得平行，再用性质求角。坑：把性质当判定；拐弯模型不会加辅助线。

拓展拔高（补习班专题）
专题1 五大拐弯模型（猪蹄/铅笔头/骨折/飞镖/8字）
猪蹄（M形，角在平行线同侧）：∠B+∠D=∠BED（两角相加）。
铅笔头/子弹头：∠B−∠D=∠BED 或反之（两角相减）。
飞镖：凹进去时 ∠B+∠D=∠BED+180° 类关系（视具体图形）。
8字模型：两线相交，∠A+∠B=∠C+∠D。
招：万变不离"过拐点作平行线"，把分散的角搬到一条线上。
专题2 平行线中的角关系综合（多折线）
例：AB∥CD，折线 B−E−F−D，∠B=30°，∠D=40°，求 ∠E+∠F。
解：过 E、F 各作平行线，把两拐点角分别拆给两侧，得 ∠B+∠D=∠E+∠F=70°。答案：70°。
专题3 平移与坐标（接八上坐标系预热）
例：线段 AB 向右平移 3 单位，A(1,2)→？
解：右移 x+3，A'=(4,2)。答案：(4,2)。
易错：
  • 判定与性质张冠李戴；
  • 同位角/内错角/同旁内角识别错；
  • 拐弯模型辅助线不会加；
  • 平移方向/距离搞错。
口诀：对顶相等邻补180判定角推线性质线推角拐弯作平行线

七下第2章 二元一次方程组

知识框架：二元一次方程 → 方程组 → 解法（代入消元／加减消元）→ 实际应用 → 三元一次方程组(选学)

① 消元是核心思想。把"二元"变"一元"。代入法（用一个表示另一个）、加减法（系数相反/相等时相加减）。

② 应用题：设两个未知数，找两个等量关系列两个方程。

③ 检验：解出的 x、y 要代回原方程组成立，且符合实际意义（如人数为正整数）。

典例：解 {x+y=5, x−y=1}。

解：两式相加 2x=6 ⇒ x=3；代入 y=2。答案：x=3,y=2

点睛：系数相反/相等优先加减法，快。

典例2：鸡兔同笼，头35脚94，鸡兔各几？

解：设鸡x兔y，{x+y=35, 2x+4y=94} ⇒ 解得 x=23,y=12。答案：鸡23兔12

点睛：脚数方程用 2x+4y，别写成 x+y。

题型·坑点

题型A 解法选择：系数简单代入，相反相等加减。坑：消元时符号错。

题型B 应用：两等量关系。坑：只列一个方程；单位不统一。

拓展拔高（补习班专题）
专题1 含参方程组（解的关系/同解问题）
例：方程组解满足 x=y，求参数。或"同解"：两个方程组有相同解，先解已知的一组再代未知组。
套路：含参先当常数解，再用条件列关于参数的方程。
专题2 应用题进阶（配套/数字/年龄/方案）
例：一张方桌配4把椅，x人做桌y人做椅，恰好配套，已知每人日产桌1张或椅4把，共20人，怎么分？
解：{x+y=20, 4×1x = 4y?} 实际 桌数:椅数=1:4 ⇒ x : 4y =1:4 ⇒ x=y，结合 x+y=20 ⇒ x=10,y=10。答案：各10人。
招：配套题先写"产品数量比=配套比"。
专题3 不定方程整数解（竞赛/压轴）
例：3x+2y=12 的正整数解？
解：y=(12−3x)/2，x=2⇒y=3；x=4⇒y=0(非正)；x=1,3 非整。故 (2,3)。答案：(2,3)。
易错：
  • 加减消元符号错；
  • 代入时括号忘加导致漏乘；
  • 应用题只设一个元或只列一式；
  • 解不符合实际（负人数）。
口诀：二元化一元相反相等用加减应用两等量两未知解要检验合实际

七下第3章 整式的乘除

知识框架：幂的运算（同底乘除／幂的乘方／积乘方）→ 整式乘法 → 乘法公式（平方差／完全平方）→ 整式除法

① 幂的运算三铁律：同底数相乘加指数，幂的乘方乘指数，积的乘方各乘各。aᵐ·aⁿ=aᵐ⁺ⁿ；(aᵐ)ⁿ=aᵐⁿ；(ab)ⁿ=aⁿbⁿ。

② 乘法公式。平方差：(a+b)(a−b)=a²−b²。完全平方：(a±b)²=a²±2ab+b²。

③ 除以单项式=系数相除、同底数幂相减、只在被除式里的字母照抄。

典例1：计算 (2x−3)²。

解：(2x)²−2·2x·3+3²=4x²−12x+9。答案：4x²−12x+9

点睛：漏−12x；(2x)²算成2x²（系数也要平方）。

典例2：a+b=5，ab=6，求 a²+b²。

解：a²+b²=(a+b)²−2ab=25−12=13。答案：13

点睛：记错符号写成+2ab得37就错。

题型·坑点

题型A 公式运算：认清a、b。坑：完全平方漏2ab；(2x)²只平方字母。

题型B 公式逆用：变形求解。坑：符号方向反。

拓展拔高（补习班专题）
专题1 完全平方公式的变形（知二求二）
例：已知 a+b=4，a−b=2，求 ab 与 a²+b²。
解：(a+b)²−(a−b)²=4ab ⇒ 16−4=4ab ⇒ ab=3；a²+b²=(a+b)²−2ab=16−6=10。答案：ab=3，a²+b²=10。
套路：和、差、积、平方和四量知二可求二，靠两个公式互推。
专题2 配方与非负性（a²±2ab+b²≥0）
例：若 x²−6x+y²+8y+25=0，求 x、y。
解：配方：(x−3)²+(y+4)²=0，平方项都≥0，故 x=3,y=−4。答案：x=3,y=−4。
招："几个非负项和为0 ⇒ 各自为0"是压轴常客。
专题3 幂的运算综合与整体代入
例：已知 2ᵃ=3，2ᵇ=5，求 2ᵃ⁺ᵇ 与 2³ᵃ。
解：2ᵃ⁺ᵇ=2ᵃ·2ᵇ=15；2³ᵃ=(2ᵃ)³=27。答案：15；27。
易错：
  • 同底数幂相乘指数"相加"记成"相乘"；
  • 完全平方公式漏2ab；
  • 混淆(a+b)²与a²+b²；
  • 系数带平方时忘平方。
口诀：同底相乘加指数完全平方别丢2ab(a+b)²≠a²+b²配方非负和为零

七下第4章 因式分解

知识框架：因式分解意义 → 提取公因式法 → 用乘法公式分解（平方差／完全平方）

① 因式分解 = 和差化乘积。与整式乘法互为逆运算。结果必须是整式乘积形式，且分到不能再分。

② 提取公因式：找各项公共的因式（系数取最大公约数，字母取最低次幂）提出来。

③ 公式法：平方差 a²−b²=(a+b)(a−b)；完全平方 a²±2ab+b²=(a±b)²。

典例1：分解 3x²y + 6xy²。

解：公因式 3xy，= 3xy(x+2y)。答案：3xy(x+2y)

点睛：提完后括号里用原项除以公因式。

典例2：分解 x²−9。

解：= x²−3² = (x+3)(x−3)。答案：(x+3)(x−3)

点睛：先认出"平方差"结构。

题型·坑点

题型A 提公因式：先提公因式再谈公式。坑：漏提负号导致括号内符号错；提不彻底。

题型B 公式法：认结构。坑：把 x²+4 当平方差（这是和，不能分）；完全平方中间项 2ab 对不上。

拓展拔高（补习班专题）
专题1 因式分解的应用（求值/整除/简便计算）
例：不用计算器，算 99²−1 能否被 100 整除？
解：99²−1=(99+1)(99−1)=100×98，含因数100 ⇒ 能整除。答案：能。
招：求值时先分解再代，常大幅化简。
专题2 先提公因式再用公式（综合）
例：分解 2x³−8x。
解：=2x(x²−4)=2x(x+2)(x−2)。答案：2x(x+2)(x−2)。
套路：顺序固定——先提公因式，再看能否用公式，直到彻底。
专题3 十字相乘法（补习班加餐，课本常不系统讲）
例：分解 x²+5x+6。
解：找两数积6、和5 ⇒ 2和3，=(x+2)(x+3)。答案：(x+2)(x+3)。
提醒：这是二次方程/分式化简的重要基础，考试常间接用到，建议提前练熟。
易错：
  • 结果不是乘积形式（写成和差）；
  • 提公因式漏负号、不彻底；
  • x²+常数的"平方和"硬拆；
  • 分解不完全（还能再分却停了）。
口诀：和差化乘积先提公再公式平方差两数和乘差完全平方看2ab

七下第5章 分式

知识框架：分式意义（分母≠0）→ 基本性质 → 乘除 → 加减 → 分式方程

① 分式有意义：分母 ≠ 0。值为0：分子=0 且分母≠0（两者同时满足）。

② 基本性质：分子分母同乘(或除以)同一个不为0的整式，分式值不变。

③ 加减：先通分（找最简公分母），再分子相加减，最后约分。

④ 分式方程：去分母化整式方程 → 解 → 必须检验（防增根）。

典例1：x 为何值时 (x−2)/(x+3)=0？

解：分子 x−2=0 ⇒ x=2，此时分母 5≠0，成立。答案：x=2

点睛：光分子为0不够，还要分母不为0。

典例2：解分式方程 1/(x−1) = 2/x。

解：两边×x(x−1)：x=2(x−1) ⇒ x=2x−2 ⇒ x=2。检验分母≠0，成立。答案：x=2

点睛：解完一定要代回验分母不为0。

题型·坑点

题型A 分式有意义/值为0。坑：值为0忘验分母。

题型B 分式方程：去分母、检验。坑：漏乘常数项；忘检验得增根。

拓展拔高（补习班专题）
专题1 分式化简求值（整体/通分技巧）
例：化简 (x²−1)/(x²+2x+1) ÷ (x−1)/(x+1)。
解：=[(x−1)(x+1)/(x+1)²] × [(x+1)/(x−1)] = 1。答案：1。
招：先因式分解再约分，比硬算快且不易错。
专题2 分式方程增根问题（含参）
例：方程 1/(x−2)=k/(x−2) 无解，求 k。
解：两边×(x−2)：1=k。若 k=1，则 1=1 恒成立但 x=2 使分母为0（增根），故无解；k≠1 时有解。答案：k=1。
套路：无解=产生增根(使公分母为0)或化简后矛盾，重点看增根对应参数。
专题3 实际应用（工程/行程分式模型）
例：甲单独做需 a 天，甲乙合做 b 天完，乙单独需几天？
解：设乙单独 x 天，1/a+1/x=1/b ⇒ 1/x=1/b−1/a=(a−b)/(ab) ⇒ x=ab/(a−b)。答案：ab/(a−b) 天。
易错：
  • 分式值为0忘验分母；
  • 通分找错最简公分母；
  • 分式方程忘检验增根；
  • 去分母漏乘不含分母项。
口诀：分母为零无意义值为零分子零且分母非零加减先通分分式解方程必检验

七下第6章 数据与统计图表

知识框架：数据收集与整理 → 条形/折线/扇形统计图 → 频数与频率 → 频数直方图

① 收集方式：全面调查(普查) vs 抽样调查。总体太大或有破坏性用抽样，样本要代表性。频率=频数÷总数。

② 三种图各管一摊。条形比数量，折线看趋势，扇形看占比。

③ 扇形圆心角= 360° × 百分比。

④ 频数直方图：把数据分组，横轴是组距，纵轴是频数。

典例：抽查200人，喜欢篮球50人，求百分比与圆心角。

解：50/200=25%；360°×25%=90°。答案：25%，90°

点睛：扇形百分比和须为100%；圆心角别忘×360°。

题型·坑点

题型 补全统计图：先算总数再求各部分。坑：扇形百分比和≠100%仍硬算；样本不具代表性却下总体结论。

拓展拔高（补习班专题）
专题1 图表信息提取与补全（结合实数/代数）
例：扇形图中A占30%、B占45%，其余为C，已知C有50人，求总人数。
解：C占比=1−30%−45%=25%；总数=50÷25%=200。答案：200人。
招：用"部分÷对应百分比=总数"反推。
专题2 频数分布直方图应用
例：80名学生身高分组，某组频数12、频率0.15，对吗？总频数应=？
解：频率=频数/总数=12/80=0.15，对；所有组频数之和=80。答案：对，总频数80。
专题3 数据决策（结合情境）
例：两种饮料销量折线，A稳步上升、B波动下降，进货建议？
解：增A减B（看趋势）。招：统计图结论要基于"趋势/占比"而非单个点。
易错：
  • 把抽样结论当精确总体值；
  • 扇形圆心角忘×360°；
  • 频数（个数）与频率（比例）混；
  • 直方图组距/频数看错轴。
口诀：条形比数折线看势扇形看占比圆心=360×百分比频率=频数÷总数
